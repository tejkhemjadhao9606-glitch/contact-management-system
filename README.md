# Contact Management System

A simple Contact Management System made using Python, Tkinter and MySQL.

## Features

- Login system
- Add contact
- View contacts
- Search contact by ID
- Update contact
- Delete contact
- Clear form
- Logout

## Technologies Used

- Python
- Tkinter
- MySQL
- mysql-connector-python

## Contact Details

The system stores:

- Name
- Phone
- Email
- Address
- Category

## How to Run

1. Install Python.
2. Install MySQL.
3. Install MySQL Connector:

```bash
pip install mysql-connector-python
